# Native half FMA 与同口径 4060 对照（2026-09-09）

用户要求先优化模型本体，第一性能里程碑是在同 NR 输入尺寸、同计时范围下追平 RTX 4060 Laptop。完整迁移目标仍未完成。本轮没有改动精确后端的35个算术文件。

新实验只在已验证的 C32/QKV 归一化和 Swin 指数位置使用 Triton 原生 half FMA，保留其他补偿算术以及 NaN 选择规则。原语、完整主体、时序流程全部与此前已认可的 FP16 快速路径比较；这不是快速路径与 NVIDIA 原生输出逐字节相同的声明，也不是 INT8 提速。

## 计算与证据

原生 tl.fma 的 half 输入编译为 llvm.fma.f16。1,048,576组随机 half 三元组有2528组 NaN payload 差异，所以没有全局替换旧 helper。归一化有限域及显式 NaN 处理、Swin/ViT 指数域分别核查后，才在实际已验证的位置启用。ViT 本体本轮未修改。

126组完整原语输出比较通过，包含14组 C32 QKV、54组多头 QKV、54组多头 Swin、4组单头 Swin。四种完整主体消融均保持输出与逻辑分派计数：旧版16.98263ms，仅归一化16.94725ms，仅 Swin16.57738ms，两者16.39090ms。各为5个轮换轮次、每轮10次重放的中位数。整体约节省0.59ms，不能称为性能突破。

NR256+完整1080p残差合成的3轮13帧成对实验，78份完整输出、种子、私有历史、返回值所有权及常量保护均通过。每轮11个连续帧均值由23.47882ms降至22.85786ms。随后完整390帧独立连续历史与已审核视频的全部低分辨率张量及完整FP32合成哈希一致；没有新画质变化，没有新增视频或全帧数组。

## 同口径比较与差距

使用4060基准相同256×256原生半精度输入纹理、零运动、默认SDR、输入驻留显存；每路径180次reset、180次temporal计时，共720份完整输出比较。新旧B580结果全字节一致。

| 完整 NR 主机调用与完成 | 连续帧均值 |
| --- | ---: |
| 4060 Laptop 固定 SF-v2 运行库 | 3.566807ms |
| B580 前一 FP16 快速路径 | 22.695921ms |
| B580 原生 half FMA 快速路径 | 22.143602ms |

B580当前约为4060的6.208倍耗时。另测静态主体时序图：设备事件区间16.442411ms、主机16.622670ms。该设备区间含图调度与空隙，不等于ALU忙碌时间或完整NR GPU耗时。它支持主体延迟无法主要归因于Python解释，但尚未量出中间读写、矩阵利用率、算术补偿等因素的各自占比。下一步应研究更大块融合和减少中间张量，而非把改成C++当作六倍提速保证。

快速reset结果与原生已有差异：mean absolute error 0.00116554、max absolute error 0.02514648。其画质标准与精确分支分开。GPU纯计时的4060 2.441643ms也不与B580完整host耗时直接相除。
