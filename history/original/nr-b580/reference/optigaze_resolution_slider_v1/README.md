# NR 输入高度滑块：冻结 480p 人脸视频

这是独立候选，不接入 ComfyUI 产品或精确版。滑块只控制 **NR 输入高度**：240、280、320、360、400、440、480，宽度保持 480×864 原视频的比例；输出一律 480×864。小于 480 时先在 GPU 上按面积缩小 RGB 与 Block 运动向量，按同一比例缩放位移；默认把缩放后的运动取整，使历史采样走整数位移快路径。随后在指定几何运行原尺寸快速 NR、启用 XPU 图重放，最后按原图引导重建回 480×864。`--motion fractional` 只用于保留分数位移的对照；它不是滑块。480 档不缩放、不取整、不重建，直接原尺寸 NR。

| NR 高×宽 | 内部补边高×宽 | 契约来源 | 人脸画质 |
|---|---|---|---|
| 240×432 | 256×512 | 实验推定 | 待审核 |
| 280×504 | 384×512 | 实验推定 | 待审核 |
| 320×576 | 384×640 | 实验推定 | 待审核 |
| 360×648 | 384×768 | 实验推定 | 先前运动取整路线已审核；本泛化实现须先与旧版逐帧散列一致 |
| 400×720 | 512×768 | 实验推定 | 待审核 |
| 440×792 | 512×896 | 实验推定 | 待审核 |
| 480×864 | 512×896 | 既有原尺寸观测 | 直接原尺寸输出，仍须本 runner 技术验收 |

所有输入高宽都能被 8 整除。补边高宽按模型内部网格选择为 128 的倍数，且处在前端单次反射允许的范围内。**实验推定**不等于 4060 的原生补边契约；它们仍需 B580 编译与逐档测试，不能仅凭表格宣布可用。每档形状首次使用可能单独编译并写入 D 盘持久 Triton 缓存；重新启动进程可以复用已生成的对应产物，但不能声称整个区间事先预编译。

## 不启动 GPU 的检查

```powershell
python -B cpu_check.py
```

它检查六份源码语法、七档宽高／补边／反射约束，逐轴检查 360 档全部 1344 个高宽坐标与旧版分数采样位置、最近中心一致，并把结果写到 `D:/Codex-NR-Experiments/nr-b580/optigaze-resolution-slider-v1/cpu-check.json`。这不验证 GPU 内核编译、速度或画质。

## 交给 Luna 的 GPU 测试

每档独立进程、先完整正确性、通过后再完整测速出片：

```powershell
python launch.py correctness --nr-height 360
python launch.py speed-video --nr-height 360
python launch.py correctness --nr-height 240
python launch.py speed-video --nr-height 240
```

其余高度同样依次传入 `280`、`320`、`400`、`440`、`480`；可选对照在同一高度的两条命令均加 `--motion fractional`。启动器使用固定 Python、14 个编译线程和 D 盘缓存／临时目录。不要同时在同一进程打开不同几何的会话。检查前四帧排除在稳态耗时之外，且输入上传、回读、散列和视频编解码不计时。

`correctness` 对同一冻结 243 帧先后运行逐算子和图重放，比较每帧模型 FP32 SHA，证实图确实重放 243 次。360 档额外比对旧已审核路线的模型 FP32 SHA。`speed-video` 必须读同输入、同代码、同运动模式、同几何且已经通过的正确性报告；重新执行图重放并逐帧复核模型 SHA。360 档再把编码前的 480p RGB8 SHA 与已肉眼审核旧视频逐帧比较。成片完整解码须恰好 243 帧，原音频与输出解码 PCM SHA 必须相同，之后才写 `speed-video.json` 和正式 MP4。各档结果分开存在 `D:/Codex-NR-Experiments/nr-b580/optigaze-resolution-slider-v1/h{高度}/{运动模式}/`。**每段新视频仍交用户肉眼审核，包括逐帧字节相同的 360 档；报告先保持待审。**

测速报告同时给四段中位耗时、相对原尺寸基线的耗时变化和吞吐变化。各档还需横向比较画质和耗时，不能把画布面积缩小当成已实现的速度收益。失败或中断不会留下新的正确性通过标志。

## 后续 ComfyUI 参数建议

产品验证后可暴露整数 `nr_input_height`，最小 240、最大 480、步长 40、默认 360。控件标注“NR 输入高度；输出仍为原视频大小”，旁边显示自动算出的输入宽度、是否首用编译、以及该档画质验证状态。运动模式单独作为高级选项，默认取整；不要将它并入高度滑块。运行时先校验该档契约与缓存，再创建该档专属会话；目前本目录没有修改节点或预编译包。
