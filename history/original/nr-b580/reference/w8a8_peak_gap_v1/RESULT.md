# B580 W8A8 峰值差距：隔离微基准（2026-09-23）

Dewey 在独占 GPU 租约下运行 `bench.py`，PyTorch 2.13.0+xpu / Triton 3.8.0。每个形状 5 个交替 block、每 block 32 次调用；首次 JIT 和 3 次预热不计时。A/W 在核心计时前完成量化，FP16/INT8 使用同一 `_matmul` 内核源和 BM16/BN32/BK32 配置。事件时间与同步墙钟均保留在 D: 原始 JSON。

| 形状 | FP16 dot Event | 预量化 INT8 dot Event | INT8 相对 FP16 |

模型特化的单独激活量化为 0.027026 ms，融合量化＋INT8 核为 0.105431 ms；大矩阵的单独量化为 0.024652 ms。模型特化上 split/fused W8A8 输出逐字节相同。

**已证实：**动态量化不是唯一拖累；即使提前量化，当前 Triton `_matmul` 的 INT8 路径在两个受测形状上都比 FP16 慢。较大形状缩小了差距但未逆转。这里的「预量化 INT8 dot」仍包含 INT32→FP32 转换、读取行/列 scale、两次乘法及 FP16 输出，并非裸 XMX 指令测速。此结果不证明 B580 硬件 INT8 乘加本身更慢，也不能单独外推整帧；当前核的 tile、布局、加载/输出和调度仍需编译产物审计或控制变量实验区分。Event 包围连续 32 次调用，包含可能的提交间隙，不能把表观 TOPS 直接当作 XMX 硬件利用率计数器。
