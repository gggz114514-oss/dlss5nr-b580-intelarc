# C512 QKV 行块复用候选：停止接入

对象是现役 RE8 360／480／540p 快速链的 C512 QKV，只将候选矩阵核的行块 BM16 改成 BM32，试图让同一权重块服务更多行。没有改 FP8／INT8 数值规则，也没有改精确版。测试在隔离的 D 盘编译缓存中先准备，再由新进程 DiskOnly 验证；每档 B-C-C-B、每段 16 帧预热＋20 帧计时，非零运动、融合历史、图重放。全部候选捕获和缓存首用门槛通过，逐帧 RGB 哈希一致。

| 网络档 | BM16 整帧中位 | BM32 整帧中位 | BM32 变化 |
| --- | ---: | ---: | ---: |
| 360p | 27.463 ms | 27.565 ms | +0.102 ms |
| 480p | 39.264 ms | 39.894 ms | +0.629 ms |
| 540p | 54.474 ms | 54.847 ms | +0.374 ms |

局部真实形状的 BM32 核也全部慢于 BM16；例如 540p 对应 768 行时约 0.129→0.149 ms，960 行时约 0.149→0.175 ms。360／480p 两个配对段都未提速，540p 一对几乎持平、一对变慢。这个方向当前应停止，不纳入三项结构组合或游戏默认值。原始结果为 [隔离测试报告](</D:/Codex-NR-Experiments/nr-b580/c512-row-weight-reuse-v1-20260927-seeded/benchmark-diskonly-smoke-v2.json>)，源码为 [`c512_qkv_row_weight_reuse_v1.py`](../game/c512_qkv_row_weight_reuse_v1.py)。本轮是短时筛选，不是长期实机性能声明；局部与整帧同向变慢已足以否决当前 BM32 实现。
