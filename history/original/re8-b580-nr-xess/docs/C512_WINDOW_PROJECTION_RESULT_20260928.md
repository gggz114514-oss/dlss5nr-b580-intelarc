# 解码 C512 窗口输出直读：原尺寸快速链实验

范围仅为《村庄》480/540p 当前快速链，不改精确分支或 360p。候选让投影矩阵核直接读取注意力的已舍入 FP8 窗口布局，省去解包成普通 HWC、裁剪和中间拷贝；矩阵 K32 累加、FP16 残差初值及末端 FP8 舍入仍按现役规则执行。八个 decoder512 块的四类窗口移位分别校验，encoder512 的末块含双输出池化，未纳入。

单块 `decoder512[1]` 局部图重放收益约 0.0065 ms，整帧约 0.06 ms。随后扩到八块并修正验收门：每次计算图捕获前后逐块比较调用计数，不能以预热期累计调用代替捕获证据。540p、480p 各做 B-C-C-B 四臂、每臂 120 帧图重放计时：

| 档位 | 两组配对中位净收益 | P95 观察 |
| --- | ---: | --- |
| 540p | 平均 **0.1191 ms/帧** | 两组候选均略好 |
| 480p | 平均 **0.0695 ms/帧** | 第二组候选比配对基线高 0.1530 ms，幅度很小，仍需在最终组合复测 |

各候选段 decoder512 的 0–7 块均在两次捕获中实际执行，候选核均为 0 spill；DiskOnly 无缺核。四臂前三帧原始 RGB 哈希相同。冻结人脸视频另以独立时域历史逐帧对照，两档各 **0/243** 原始浮点 RGB 差异、各 2 次捕获和 241 次重放。

详细报告位于 `D:/Codex-NR-Experiments/nr-b580/c512-window-all-20260927/`，包括 `full-480-benchmark.json`、`full-540-benchmark.json`、`video-bytes-480.json` 和 `video-bytes-540.json`。以上是隔离候选收益；是否进入游戏默认链，须以与 pre 融合共同启用后的整帧配对和安装缓存验证为准。
