# C256 QKV 直写窗口布局：游戏快速链路实验

2026-09-27。范围是《村庄》现役 480/540p 原尺寸快速链路，基线包含已安装的 C64、C128、C32 与 post 联合优化；精确分支未改。候选把 C256 的 QKV 矩阵输出直接写到注意力需要的窗口布局，保留现役 FP16 截断、归一化与 FP8 舍入顺序。它减少一个中间张量的写读及后续 pack 发射，**不是把 C256 改成 INT8**。

单块候选为 `encoder[3][1]`，输入形状在 540p 是 48×72×256，在 480p 是 40×64×256。BM16、BM32 的 Q/K/V 均与原实现逐字节一致，图重放哈希也一致；每段 120 次。完整记录位于 `D:/Codex-NR-Experiments/nr-b580/c128-c256-qkv-boundary-20260927/c256-one-{540,480}-{prepare,benchmark}.json`。

| 档位 | 原版两段中位 | BM16 两段中位 | BM32 两段中位 |
| --- | ---: | ---: | ---: |
| 540p | 0.1586 / 0.1574 ms | 0.0977 / 0.0966 ms | **0.0798 / 0.0797 ms** |
| 480p | 0.1218 / 0.1200 ms | 0.0785 / 0.0777 ms | **0.0646 / 0.0644 ms** |

BM32 局部中位数约快 46–50%。编译元数据中 BM16/BM32 共享内存分别 1024/2048 字节、scratch 均为零；当前缓存元数据不提供寄存器与 spill 数，不能称已经排除寄存器溢出。540p BM32 第二段 P95 有波动，因此继续以完整帧配对为准。

16 块扩展位于 `game/c256_qkv_direct_pack_all_v1.py`，Astra 已静态核对全部目标、形状和覆盖链。现役组合加上 16 块 BM32 的 B-C-C-B 配对中，每段测 120 帧图重放；每臂重置及随后两帧 RGB 字节一致，现役组合捕获门和新增 16 块捕获计数通过，独立进程 DiskOnly 无缺核。完整记录：`D:/Codex-NR-Experiments/nr-b580/c128-c256-qkv-boundary-20260927/c256-all-{540,480}-{prepare,benchmark}.json`。

| 档位 | 两次基线中位 | 两次候选中位 | 中位净收益平均 |
| --- | ---: | ---: | ---: |
| 540p | 48.407 / 48.077 ms | 47.185 / 46.810 ms | **1.245 ms/帧** |
| 480p | 35.741 / 35.727 ms | 34.809 / 34.798 ms | **0.931 ms/帧** |

两档 P95 净差亦同向为正（540p 两组 +0.608/+1.144 ms；480p +1.230/+0.924 ms）。冻结人脸视频的基线/候选各自持有独立时域历史，在两档**各 243 帧原始浮点 RGB 全部逐帧字节一致**，差异 0/243；每臂捕获两次、重放 241 帧，16 块在捕获期均命中，记录为 `c256-video-bytes-{540,480}.json`。未编码视频，也未单独让用户看画面；这一步按已获许可的字节一致门验收。

E 源码覆盖候选全配置预编译/新进程 DiskOnly 检查 **168/168、168/168**，两档新捕获门均有 `c256_all_sixteen=true`。备份 G 版旧组合模块后安装三文件，安装缓存再通过 **168/168、168/168**，补编七个特化，游戏运行期未新增缓存文件。报告为 `precompile-c256-e-overlay.json`、`precompile-c256-installed.json`；备份在 `D:/Codex-NR-Experiments/nr-b580/game-c256-direct-backup-20260927/`。

实机监看：480p 连续达到 354 帧与 278 帧图重放，540p 达到 830 帧图重放；540p 新捕获的 `c256_all_sixteen` 和其余组合门直接读到 true。480p 捕获瞬间没有被状态采样命中，健康状态正常且继续图重放，是间接通过证据。用户肉眼确认两档画面正常。监看结束前后游戏进程已退出，应用日志未见对应崩溃条目；现有证据不能判定退出原因。安装后的 480/540p 仍应在后续使用中留意稳定性，特别是 480p 新捕获门的直接读数。
