**研究更新 · 2026-09-14 · 原尺寸快速算术与低分辨率归因**

前两项同批约3.40倍吞吐差，排除传输、运动估计、读写和编解码。快速版并非原版字节等价，也未达到24/30fps实时。全片全画面RMSE（0..255单位）从NR256的4.935降到原尺寸快速的2.161；这是单段素材的证据，不是通用质量保证。

新增源码在[snapshots/2026-09-14](snapshots/2026-09-14/README.md)，包含精确优化、原尺寸快速适配、NR256实验路线和对应诊断/测速程序。**不是一键可运行的ComfyUI节点发行包**；权重、校准资产、私有运动实现和视频素材不随本仓库分发。

本项目记录如何以一台 RTX 4060 Laptop 为计算参考，将固定 DLSS 5 Neural Rendering（NR）运行库的计算恢复为可在 Intel Arc B580 独立执行的后端。发布重点是**恢复过程、失败案例、数值规则和验证方法**；后端源码是对应阶段成果的一部分。

工作起点是社区公开的权重解析与不完整计算图。直接运行这张图时输出明显不正确。我们通过原生捕获、独立 CUDA 内核重放、寄存器边界诊断及 CPU/B580 对照，逐步恢复了实际计算，而不是用蒸馏模型拟合最终画面。

参考对象固定为社区 RTX40 兼容 **310.8.SF-v2**、RTX 4060 Laptop、驱动616.86。这里的“精确”指**在记录的输入、状态、控制及源码版本下，最终 RGB 和相应历史状态的原始字节与该固定参考一致**。没有证明它与官方 RTX50 运行库等价，也没有证明任意输入和所有参数组合的普遍等价性。

| 内容 | 用途 |

## 2026-09-09历史阶段成果

- 完成原权重模型的独立 B580 RGB→RGB 执行；最终验收不注入4060中间特征或上一帧输出。
- 精确路径已在记录的单帧、运动、尺寸和控制/UI用例中逐字节对齐。当前35文件版本有55帧正式回归及13帧主目录复验；历史版本的更多比较单列，不合并成当前版本覆盖。
- 公开关键恢复方法：原生矩阵累加与舍入、FP8边界、half FMA中点、窗口/权重布局、五点历史采样、原生倒数及状态所有权。
- 另有允许画面变化的快速路径：同256×256输入与完整host计时口径，B580约22.14ms，4060约3.57ms；**尚未追平4060**。NR256残差路线的390帧视频已接受，最新优化与此前快速版字节一致。

最后一项不属于精确分支的原生字节一致声明，也不等于1080p全尺寸网络已达到22ms。详见[阶段成果](docs/05-milestone.md)。
