这些是相对于原 FP16 路径的内部特征误差，不能转换成最终 RGB 画面误差。
余量 1.25 用于接下来的 GPU 原型筛选，不作为最终校准或画质批准。各块独立
使用一个冻结帧的输入，48 个交错 token 校准、16 个同帧 token 留出；相关性
很高，尚未验证跨帧、运动、曝光或误差逐层累计。

方案：入口动态按行量化 INT8，扩张权重按列 INT8；立方激活保留 half 运算，
内部 FP8 边界换成静态按通道 INT8。隐藏尺度先合并进收缩权重，再量化权重。
收缩使用完整 INT32 累加，保留 half 残差和出口 FP8。GPU 可用一个长累加或
多份 INT32 部分和实现相同有界整数求和，两者仍须实测速度与数值。

原始隐藏值存储 524288 字节，计划 INT8 隐藏值 262144 字节，静态尺度另需
16384 字节；该局部大小不代表整个模型显存减半，也不是速度结论。

254 种有限 FP8、126 个正数中点舍入、正负零、饱和、INT8 舍入和零尺度检查
通过；ViT0 扩张权重完整字节匹配既有捕获；16/16 尺度合并代数检查通过。
未保存量化权重，保留少量尺度与输出数组供下一轮 GPU 对照。

默认仍 nr256_selected_stack_v4。新 GPU 原型先要求与 CPU 新量化计算一致，
并对比当前 FP16 完整 FFN 段；有速度收益才继续整模型及用户视频审核。
