# 历史采样融合：本地阶段记录（2026-09-09）

本次在已审核的 NR256 FP16 快速路线中，保持输出不变，把历史图像的五点采样融合为一个 Triton 核心。固定 256×256 输入、输入已在显存中、完整 NR 调用并等待完成的连续帧平均耗时，从 18.102812 ms 降到 14.372799 ms，减少 20.6046%。同口径固定 RTX 4060 参考为 3.566807 ms，当前 B580 耗时仍为其 4.0296 倍。完整迁移和性能持平目标仍未完成。

用户要求后续先保留在本地，取得阶段成果再发布。本次仅保存本地代码和证据；不更新公开仓库或 Release。正式精确后端的 35 个 Python 文件保持原样。这里的字节一致是相对已审核的 B580 FP16 快速路线；该路线与 NVIDIA 原生结果已有经用户接受的差异，不能表述为本次快速模式与 NVIDIA 字节一致。

## 为什么改这一处

先在上一版本（隔离 Triton 3.8 + K8 平铺）上测量完整调用路径，得到历史采样约 3.904033 ms、常量检查约 1.226430 ms、模型主体完成等待约 12.392561 ms。这里的历史采样是 NR 使用运动向量重采样上一帧；不是用户在隔壁项目实现的 DIS 或 block 运动估计。

在计时区间之外抓取 11 个实际历史输入及完整分子、倒数输出，共 44 个数组、18,743,296 原始字节。以这些实际操作数核对新融合实现。未改动运动估计、模型权重或网络精度。

## 实现与支持范围

选择 `fused_square_history_v2.py` 和 `fused_graph_history_warp_v2.py`，默认 B64、4 warps。数学仍保留原有 FP32 运算及显式 FMA 次序、1/256 纹理系数、活动像素的 14 位定点对齐、INT64 加权求和、半精度 ties-away 舍入、负零和原生倒数表。未用通用 grid_sample 近似替代。

融合构建器支持连续布局的半精度 256×256 或 512×512 RGB 历史，以及同尺寸半精度或 FP32 运动向量。其他精度和布局通过原构建器回退；基类继续控制尺寸与设备等适用条件。此次完整模型验证范围是 NR256 快速路线；不能外推到任意分辨率、HDR、任意非有限图像输入或全部控制参数组合。

适配器继承原 `GraphHistoryWarp`，只替换图构建方法。保留倒数表身份和版本检查、返回前状态读回、调用方独立输出副本、图池之外的持久输入输出，以及关闭和作用域恢复行为。无效输入在模型提交历史之前拒绝。

V1 的有效数据测试匹配，但未拒绝非有限运动，因此完整测试失败，不选用。V2 增加对转为半精度之后运动向量的显式有限性检查；原适配器与 V2 均拒绝 NaN/Inf。坐标 min/max 对 NaN 的处理可能解释 V1 行为，但没有逐指令追踪证明这一根因。保留 V1 源码和失败报告，不回写历史记录。

## 正确性证据

- 19 组基元完整输出匹配：11 个实际历史输入，以及零运动、全部 63,488 种有限半精度编码的确定性混排、正负零、系数半步、边缘钳位、512 尺寸、FP32 运动舍入、FP32 历史回退。混排覆盖编码值，不是所有输入组合的穷举证明。
- NaN/Inf 运动拒绝、倒数表替换与版本变化拒绝、关闭后拒绝均通过。输出在之后重放中保持独立，调用方写输出不污染后续结果；输入和倒数表字节保持不变。
- 78 个完整残差流程输出、历史、重置、进度回退和常量/所有权检查通过。另在模型层验证无效运动和替换倒数表不会提交新历史或重放模型主体。
- 完整 390 帧、独立连续历史验证通过：每帧完整低分辨率 NR 字节及完整 1080p FP32 合成输出哈希与已审核视频对应结果一致。重置可复现首帧；无新视频编码或完整大帧转储。
- 同原生参考输入的 720 次完整输出均与优化前及冻结的 Triton 3.7.2 对应结果一致。已审核画质没有新增变化，按用户要求无需重复肉眼审核。

保存后的 CPU 审计重新读取引用数组、认证报告与源文件、核对 GPU 测试的完整输出收据。390 帧审计读取 780 个数组，存储字节合计 2,503,020,263。该审计不独立执行模型数学；不能把认证输出收据表述成独立 CPU 算法复现。

## 当前选择与下一步

选用隔离 Triton 3.8、K8TiledMatrices、FusedHistoryWarp V2，并保留上一版 native-half HeadLayout/FusedSwin、GraphFront V6、FusedBatched small、FusedSplit V2、C32 LUT bm32、ViT projection V3、FusedFront 和 ResidualScale256。先前没有稳定完整调用收益的 C32Tail 不选用。

历史采样已降至约 0.15 ms，模型主体的诊断完成耗时仍约 12.5 ms，是下一步主要对象。主体本次未改动，其小幅计时波动不计为主体加速。继续定位当前栈中注意力和高通道矩阵的实际开销，保留常量变更检测；不要用移除检查或把设备事件区间当作纯计算忙碌时间来缩小与 4060 的差距。

生产 OptiScaler/XeSS/ComfyUI 接入、更多尺寸、HDR 和控制行为等仍有待完成。本次是可复用实验组件和本地性能进展，不是完整迁移完成声明。
